# Сүхбаатарын хурд — сугалааны эрх шалгах

Монгол үндэсний хэв маягтай, утасны дугаараар сугалааны эрх шалгах веб систем.

## Үндсэн шаардлага
- Олон нийтэд: зөвхөн 8 оронтой утасны дугаараар хайна.
- Хайлтын үр дүн: гүйлгээний огноо, утасны дугаар, сугалааны эрхийн тоо гэсэн 3 талбар л харагдана.
- Нийт оролцогч, нийт сугалааны эрхийн статистик нь зөвхөн админ хэсэгт байна.
- Facebook хуваалцах үйлдэл нь зөвхөн админ хэсэгт байна.
- Excel импортын түүх, алдаа, өмнөх импорт руу сэргээх боломж зөвхөн админ хэсэгт байна.

## Технологи
Next.js App Router, TypeScript, Tailwind CSS, PostgreSQL, Prisma, ExcelJS.

## Эхлүүлэх
1. `npm install`
2. `.env.example`-ийг `.env` болгон хуулж тохируулна.
3. `npx prisma migrate dev`
4. `npm run dev`

Одоогийн эхний commit нь интерфэйс болон төслийн суурийг бэлтгэж байна. Бодит Excel импорт, хайлт, нэвтрэлт нь өгөгдлийн сан болон орчны хувьсагч тохируулсны дараа ажиллана.
